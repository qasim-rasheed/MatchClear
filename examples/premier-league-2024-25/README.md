# Premier League practice tournament

Practice the organizer's job using Arsenal, Chelsea, Liverpool and Tottenham Hotspur, with shirt references from the 2024/25 season.

This is an independent practice example, not an official league tool or endorsement. Quantities, inventory and prices are exercise assumptions.

## Included files

- `teams.csv`: four teams, eight shirts each (S: 2, M: 4, L: 2).
- `fixtures.csv`: four historical fixtures for a small practice subset.
- `shirt-and-model-map.csv`: shirt choices and illustrative costs; a reference checklist, not an import file.
- `people/`: two Pexels stock adult photos, credited in [CREDITS.md](CREDITS.md).
- `sources.json`: shirt details, fixture sources and assumptions.
- `shirts/`: local reference photos, when present. These retailer images are excluded from Git; use the linked source pages or supply your own permitted photos.

## Walk through the app

1. Start the app and worker using the main README.
2. Create an event, choose GBP and set a £300 practice budget.
3. In **Event → Teams & sizes**, import `teams.csv`. Check the preview before saving.
4. In **Matches**, import `fixtures.csv`.
5. In **Shirts**, add Arsenal home, Liverpool home and away, Chelsea home and Tottenham home. Use the checklist for colours and assignments. For this exercise, the home shirts are assumed owned; Liverpool away is an illustrative £35 per shirt.
6. In **Preview**, choose a team and shirt. Upload a permitted model photo and the matching actual shirt photograph. Confirm permissions, then generate with YouCam.
7. Inspect the result against its reference. Accept usable outputs, reject inaccurate ones, and mark and confirm the shirt area. Repeat for the options you want to compare.
8. In **Compare**, review each opposing pair in all eight views. Record your own decision and reason. Review Liverpool's alternative separately where relevant.
9. In **Plan & order**, run the planner. Complete any missing reviews, inspect the selection and confirm a current complete plan.
10. Create the seller brief and open **Print / PDF**, **CSV** or **JSON**.

Do not approve a combination merely to finish the exercise. Rejected or inconclusive previews and comparisons are legitimate results. New renders use your API units; imports, comparisons and planning do not.

## About the video example

The recorded **My Premier League Kit Test** is a separate saved local event with six pairings and edited practice inputs. It is not automatically installed by these four-fixture CSVs. Saved renders, reviews and the local database are not shipped with this pack.
